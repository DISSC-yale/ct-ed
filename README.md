# Connecticut Education Funding

This is a web tool to help explore Connecticut education data, and effects of adjusting a funding formula.

## Data Sources

- Education data from [EdSight](https://public-edsight.ct.gov).
- Funding formula inputs from provided worksheets.

## Development

You can run the site locally:

```sh
npm run dev
```

With a development server running, you can also run interactive tests:

```sh
npm run test:interactive
```
